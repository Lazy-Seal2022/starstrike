# features

## Overview
Gameplay feature systems rollup for the web prototype.

## Subdirectories & Boundaries
- **[ai](./ai/README.md)**: Autonomous enemy ship behavior, target tracking, and combat navigation.
- **[combat](./combat/README.md)**: Weapon firing, projectile trajectory simulation, and damage calculation.
- **[mining](./mining/README.md)**: Asteroid breakup mechanics, crystal drops, and mineral collection.
- **[movement](./movement/README.md)**: Newtonian space physics simulation with inertia, space drag, and forward thrust.
- **[progression](./progression/README.md)**: Ship stat tier upgrades and multi-tier ship evolution system.
- **[regeneration](./regeneration/README.md)**: Passive shield restoration and blaster energy recharge simulation.
- **[world](./world/README.md)**: Arena boundary enforcement and asteroid field procedural distribution.
