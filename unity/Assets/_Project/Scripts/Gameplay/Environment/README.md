# Environment

## Overview
World entities, destructible space obstacles, resource crystals, powerup items, and environmental sector hazards.

## Components
- `Asteroid.cs`: Destructible obstacle with procedural fracturing and gem drops.
- `GemCrystal.cs`: Mineable resource gem item granting XP/score.
- `PowerUpItem.cs`: Collectible combat booster (Shield boost, Overcharge, etc.).
- `WeaponPickupItem.cs`: Mid-run weapon module drop.
- `SectorHazardController.cs`: Environmental hazard fields (radiation belts, nebula storms).
