# Ship Classes

## Overview
Modular naval class builders defining ship archetypes, weapon hardpoints, socket geometries, and hardware configurations for each military hull class.

## Class Builders
- `FighterClass.cs`: Light strike fighters, interceptors, and recon scouts (Ares, Delta Scout, Viper Interceptor).
- `FrigateClass.cs`: Fast wolfpack escorts and tactical gunboats (Viper Frigate, Goliath Miner).
- `DestroyerClass.cs`: Anti-capital heavy gunships fielding heavy torpedo batteries (Cerberus Destroyer).
- `CruiserClass.cs`: Fleet backbone warships boasting 360-degree independent turret arcs (Aegis Cruiser).
- `CarrierClass.cs`: Fleet hive commanders housing autonomous escort drone hangars (Vanguard Carrier).
- `BattleshipClass.cs`: Superheavy citadel dreadnoughts fielding spinal superweapons (Titan Dreadnought).
