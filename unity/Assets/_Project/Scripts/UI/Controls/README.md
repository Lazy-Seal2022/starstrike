# Controls

## Overview
Reusable mobile and desktop input elements, virtual joysticks, touch buttons, and screen-safe area layout helpers.

## Components
- `VirtualJoystick.cs`: Floating or fixed dynamic touch joystick with deadzone and normalized vector output.
- `TouchButton.cs`: High-response virtual fire/ability button.
- `SafeArea.cs`: Hardware notch and cutout padding for edge-to-edge mobile displays.
