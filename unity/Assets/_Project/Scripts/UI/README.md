# UI

## Overview
User interface presentation layer blueprint.

## Subdirectories & Boundaries
- **[Common](./Common/README.md)**: Procedural sprite builders and TextMeshPro typography layout helpers.
- **[HUD](./HUD/README.md)**: In-game flight HUD, status gauges, upgrade drawer, floating combat text, and touch joystick.
- **[MainMenu](./MainMenu/README.md)**: Title screen, game mode selection (PvE / PvP), and hangar ship selector.
- **[Minimap](./Minimap/README.md)**: Tactical radar minimap tracking friendly ships, hostiles, and objectives.
- **[Network](./Network/README.md)**: Multiplayer room lobby interface and live leaderboard scoreboards.
- **[Settings](./Settings/README.md)**: Modal settings dialogue for audio mixing and customizable flight control schemes.
