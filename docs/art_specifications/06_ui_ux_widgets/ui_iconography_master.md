# Sprite Specification: Iconography Master Sheet (`ui_icons`)

> **Category:** UI/UX Design System — Vector Iconography  
> **Target Audience:** UI Vector Artist & Icon Designer  
> **In-Game Role:** Weapons, tactical skills, attributes & economic currency icons  

---

## 1. Iconography Style Rules

All icons in StarStrike must adhere to a strict visual syntax:
* **Grid Format:** **64 x 64 pixels** (with 4px internal safety padding).
* **Stroke Weight:** 2px consistent outer vector stroke; 1px inner detail lines.
* **Palette:** Pure white `#FFFFFF` vector glyphs (which can be tinted dynamically via Unity UI Image Color) with integrated emissive elements.
* **Angles:** 45-degree angled chamfers and diagonal accents.
